# SERIAL — пульт і CAM для grblHAL

SERIAL — це термінал, пульт і маленька CAM-програма для верстатів на [grblHAL](https://github.com/grblHAL)
прямо на кишеньковому PicoCalc (або HAT). Він підключається до верстата по USB чи по Wi-Fi (telnet), рухає
осі, запускає G-code з ходом виконання, а ще має редактор фігур і тексту, з якого одразу виходить готовий
G-code.

| Редактор фігур | Перегляд траєкторії й запуск |
|:---:|:---:|
| ![editor](gif-picocalc/serial-editor.gif) | ![toolpath](gif-picocalc/serial-toolpath.gif) |

*Коло, прямокутник-карман і текст «PicoCalc Привіт» → G-code → перегляд, запуск, хід виконання. Записано з
екрана PicoCalc.*

## 1. Профілі й підключення

SERIAL тримає кілька **профілів** — по одному на машину. Початково їх два:

| Профіль | Зв'язок | Пульт |
|---|---|---|
| **3D-сканер** | USB (`/dev/ttyACM*`, `/dev/ttyUSB*`) | Y, поворотний стіл (M102–M104), серво ST3215 (M101) |
| **Верстат** | мережа: telnet grblHAL, порт 23 | X Y Z, шпиндель |

**F1 → Профіль** — вибрати профіль, перейменувати, змінити тип (сканер / верстат), осі пульта, додати новий.
У кожного профілю свої порт або адреса, кінець рядка, тека файлів, оберти шпинделя, параметри редактора.

**Підключення по мережі** — найпростіше набрати в рядку вводу:

```
telnet 10.80.39.133
```

і натиснути Enter (порт — через пробіл, якщо не 23). Те саме є в **F3 → Адреса**. Якщо верстат не
відповідає, SERIAL повторює спробу кожні 5 с і сам перепідключається після обриву. Угорі видно стан:
зелене `10.80.39.133:23` — з'єднано, помаранчеве — з'єднується, червоне — немає зв'язку.

**USB** — порт вибирається сам (перший ACM, потім USB), або вручну в **F3**. Плата, що перезавантажилась,
під'єднується знову сама. F3 → «Відкрити в minicom» передає порт справжньому minicom.

## 2. Термінал

Головний екран SERIAL — це термінал з двома вікнами:

* **верхнє** — ваші команди й перші 1–2 рядки відповіді на кожну, `ok` / `error` / `ALARM` з поясненням коду
  українською;
* **нижнє** — повний вивід, усе, що надіслав пристрій. **F2** або **Tab** ховає / показує його.

Рядок стану під заголовком: стан (`Idle`, `Run`, `Hold`, `Alarm`…), координати, подача й оберти, поля плагінів,
корекції, **червоним — активні входи** (кінцевики, щуп, двері).

* `?` `!` `~` на порожньому рядку надсилаються одразу (команди реального часу: стан, пауза, продовжити).
* **↑ / ↓** — історія команд, **PgUp / PgDn** — прокрутка.
* **Ctrl+X** — програмне скидання grbl. **Backspace на порожньому рядку в стані Alarm — `$X`** (зняти блокування).
* **Ctrl+E** — вікно пояснення останньої помилки / аварії: код українською, опис від самої прошивки (`$EE` /
  `$EA`, разом з кодами плагінів), що робити, після якої команди чи рядка файлу.
* Вихід — `quit` + Enter або **F1 → Вихід** (Esc лише очищає рядок).

> grblHAL після `error:N` відкидає наступні рядки G-code з тим самим кодом, доки не прийде порожній рядок.
> SERIAL надсилає цей порожній рядок сам, тож після помилки можна просто працювати далі.

## 3. Пульт верстата

**Ctrl+T** або **F1 → Пульт**. Великі робочі координати X Y Z і поруч машинні, стан, подача, шпиндель.
Стан опитується 5 разів на секунду; зелена крапка блимає на кожну відповідь, червоне «немає ?» — відповідей
немає понад секунду.

| Клавіша | Дія |
|---|---|
| ← → | X |
| ↑ ↓ | Y |
| `/` `\` (або PgUp / PgDn) | Z вгору / вниз |
| натиск | один крок; **утримання** — безперервно, відпустили — стоп одразу |
| `+` `-` | крок 0,01 / 0,1 / 1 / 10 / 100 мм (подача під крок) |
| `x` `y` `z` | нуль осі в поточній системі координат (`G10 L20 P0`) |
| `0` | нуль усіх осей |
| `s` | шпиндель: увімкнути — двічі за 2 с, вимкнути — одразу |
| `,` `.` | оберти шпинделя |
| F2 / F3 | подача −10 % / +10 % |
| F4 | подача 100 % |
| F5 | швидкі 100 → 50 → 25 % |
| **Backspace** | `$X` — зняти Alarm |
| **ПРОБІЛ** або Ctrl+X | **аварійна зупинка** (jog cancel + скидання) |
| `e` | пояснення помилки |
| F1 | довідка по клавішах |
| Esc | назад у термінал |

> Програмна аварійна зупинка **не замінює** апаратну кнопку E-stop.

HAT: джойстик — X / Y, KEY1 / KEY2 — Z, натиск — крок, KEY3 — стоп (двічі — вихід).

## 4. Пульт 3D-сканера й майстер сканування

Профіль **3D-сканер**: Y, кут поворотного столу (`TBL`, і абсолютний `TBLABS`), кут серво ST3215 і його межі
(`$451` / `$452`).

| Клавіша | Дія |
|---|---|
| ↑ ↓ | Y (крок `+` / `-`) |
| ← → | стіл на крок (`M104`); `t` / `T` — крок 1 5 10 15 30 45 90° |
| `r` / `l` | крутити стіл за / проти годинникової (`M102`) |
| `o` | зупинити стіл (`M103`) |
| `/` `\` | серво на крок (`M101`), `v` / `V` — крок 1 / 5 / 15° |
| `y`, `0` | нуль Y, нуль усіх осей |
| Enter | продовжити після `M0` |
| ПРОБІЛ | аварійна зупинка (скидання зупиняє і стіл) |

**Майстер сканування** (`w`): позицій на оберт, швидкість столу, заспокоєння після повороту, що робити на кожній
позиції (пауза / `M0` — чекати Enter / імпульс на вихід `M64`–`M65`), кути серво й висоти Y (списки через кому:
для кожної висоти й кута — повний оберт), розкрутити стіл після оберту. Унизу — кількість позицій і час.
«Створити файл» пише `~/gcode/scan/scan-….nc` і відкриває його; «Створити й запустити» — одразу запускає.

## 5. Файли G-code

**F4** — файл:

* **Відкрити файл…** — тека `~/gcode` (`.nc .gcode .ngc .tap .gc .cnc .txt`). Після відкриття — розміри X Y Z і
  оціночний час.
* **Запустити весь** — рядок за рядком, наступний після `ok`; на помилці — пауза з номером рядка.
* **Покроково** — Enter надсилає наступний рядок.
* **Пауза / продовжити** (`!` / `~`), **Стоп** (скидання).
* **Перегляд траєкторії** — див. наступний розділ.
* **Межі й перевірка** — діапазон кожної осі, довжина рухів, час, і **чи вміщується файл у хід верстата**
  (`$130`–`$132` з урахуванням нуля; потрібен хомінг).
* **Обвести межі** — G0 по прямокутнику X/Y на поточній висоті Z і назад (лише Idle, з підтвердженням): видно,
  чи заготовка на місці.
* **Корекції подачі…**

Смуга ходу показує відсоток за оціночним часом, скільки минуло й скільки лишилось (оцінка підлаштовується під
реальну швидкість). Наприкінці й при помилці — звуковий сигнал.

## 6. Перегляд траєкторії й запуск

**F4 → Перегляд траєкторії**. Траєкторія у масштабі (XY, `v` — XZ): швидкі рухи сірі, робочі — колір за
глибиною (помаранчевий — найглибше, бірюзовий — вгорі), виконане — зелене, кружечок — де зараз інструмент.

**Хрестик і вікно G-code.** Стрілки водять хрестик по траєкторії (утримання — швидше); найближчий рух
підсвічується білим, а у вікні внизу — його рядок. **Tab** переводить фокус у вікно G-code: ↑ / ↓ — рядок за
рядком, ← / → або PgUp / PgDn — по 5; рух рядка підсвічується на траєкторії.

Над рядками — для вибраного рядка **Z** (глибина руху, для заглиблення «звідки → куди») і **коли до нього
дійде**: «від старту ≈…», а під час виконання «через ≈…», «зараз», «виконано».

**Запуск звідси:**

* `r` — з початку;
* **Enter у вікні G-code — з цього рядка.** SERIAL спершу відновлює стан, у якому файл був би на цьому рядку:
  режими (`G21 G90`, площина, система координат), шпиндель з обертами й 3 с на розгін, охолодження, підйом на
  безпечну Z, переїзд у X Y перед рядком, опускання, подача. Усе це показано в підтвердженні.

Під час виконання ви лишаєтесь у перегляді: смуга ходу з часом, вікно й хрестик ідуть за рядком (стрілки —
роздивитися, `f` — знову стежити), **пробіл** — пауза / продовжити, **Ctrl+X** — стоп. Esc закриває перегляд, а
файл виконується далі. **F1** — довідка.

## 7. Редактор фігур

**F1 → Редактор фігур** (у профілі верстата). Поле в міліметрах, нуль внизу ліворуч (червона й зелена риски —
осі X і Y), розмір поля — з ходу верстата.

### Хрестик

* стрілки — на крок сітки; утримання повторює, через 1,5 с утричі швидше;
* крок сітки (0,1 / 0,5 / 1 / 2 / 5 / 10 мм) підбирається під масштаб, `g` / `G` — свій;
* `+` / `-` — масштаб навколо хрестика, `0` — усе поле, `h` — хрестик у нуль.

### Фігури

| Клавіша | Фігура | Точки (Enter ставить) |
|---|---|---|
| `c` | коло | центр, точка на колі |
| `e` | еліпс | центр, кут рамки |
| `r` | прямокутник | два кути (радіус кутів — у числах) |
| `a` | дуга | центр, початок, кінець; `d` — напрям |
| `l` | лінія | два кінці |
| `t` / `T` | текст у прямокутнику / колі | див. [розділ 8](#8-текст-для-гравіювання) |

Поки ставите точки, фігура малюється наживо, внизу — її розмір. Backspace прибирає останню точку, Esc —
кінець інструмента.

### Редагування готової фігури

Наведіть хрестик на лінію фігури (вона жовтіє) або натисніть **Tab** — хрестик перескочить на наступну фігуру.

* **Enter — точки, як при малюванні.** Квадратики — точки фігури: кути, центр, точка радіуса, кінці. Хрестик на
  точку (Tab — наступна), Enter — взяти, стрілки — тягнути, Enter — покласти, Esc — повернути як було. Центр (у
  лінії — середина) переносить усю фігуру.
* **Пробіл (або `n`) — точні числа.** Перше поле — **глибина** фігури (0 — загальна). Далі прив'язка X / Y —
  **лівий нижній кут** (для кола й еліпса — кут описаного прямокутника) **або центр**, розміри, радіус кутів,
  кути дуги, обробка. Фігура змінюється наживо; набрали число — `s` (готово) або Enter (далі), Esc — скасувати.
* **Del / Backspace** — видалити, **`u`** — скасувати останню зміну.

### Обробка і глибина

Для замкнених фігур (коло, еліпс, прямокутник, замкнений контур) поле «Обробка»:

| Обробка | Як іде фреза |
|---|---|
| по лінії | центром фрези по лінії |
| зовні | зсунута назовні на радіус — деталь точно за розміром |
| всередині | зсунута всередину на радіус — отвір точно за розміром |
| **карман** | вибирає все всередині: кільця від центру назовні з кроком «Карман: крок, % фрези», останнє — по стінці |

**Глибина** — своя для кожної фігури (перше поле чисел) або загальна. На кресленні біля фігури зі своєю
глибиною видно жовте «↓2.5». Глибина ріжеться в кілька проходів із загальним кроком по глибині; відкриті
фігури (лінія, дуга) проходяться туди й назад.

**`p` — параметри обробки:** безпечна Z, загальна глибина, крок по глибині, подачі XY і Z, **діаметр фрези**
(видно вгорі праворуч: «Ø3.175 ↓1»), крок карману, оберти шпинделя (0 — без `M3`), розмір поля.

### Файли, автозбереження

* Креслення — **`~/gcode/shapes/НАЗВА.svg`** (звичайний SVG: відкривається в браузері, Inkscape), поруч —
  **`НАЗВА.nc`** з G-code.
* Обидва файли **зберігаються самі** за секунду після кожної зміни: ● — ще ні, ✓ — збережено.
* Нове креслення називається `shape` (`shape-2`, … якщо зайнято).
* **`s` — зберегти як**: нова назва (робоче `shape` просто перейменовується).
* **`o` — відкрити**: список креслень і «+ нове креслення».
* **Esc двічі** (за 2 с) — вийти: G-code відкривається в SERIAL (F4 — перегляд, межі, запуск). Одне Esc лише
  скасовує інструмент, вибір чи вікно.
* Редактор відкриває креслення відкритого в SERIAL файлу, інакше останнє.

## 8. Текст для гравіювання

* **`t`** — текст **у прямокутнику** (два кути рамки): літери вписуються в рамку якомога більше, без
  спотворення, під заданим кутом нахилу.
* **`T`** — текст **по дузі або колу** (центр і точка на лінії літер): літери йдуть по колу, як на печатці.
* Одразу відкривається поле тексту: набирайте, **Tab — EN / UA** (стандартна українська розкладка), **`|` —
  новий рядок**, Enter — готово.

У числах тексту (пробіл): глибина, текст, **шрифт** (DejaVu Sans / Serif / Mono, звичайний і жирний),
**обробка**, **розміщення** (у прямокутнику / по дузі) і далі:

* у прямокутнику — кут нахилу, прив'язка, X, Y, ширина, висота рамки;
* по дузі — центр X / Y, радіус лінії літер, **середина тексту** (кут: 90° — верх, −90° — низ), **дуга в
  градусах** (літери розтягуються на неї; **360 — повне коло**; 0 — розмір за «висотою літер»), висота літер,
  **напрям**: «зверху, за год.» — літери назовні, «знизу, проти год.» — до центру, текст читається внизу кола.

Напис зверху й напис знизу на одному колі — як на печатці — це два тексти з однаковим центром і радіусом.

| Обробка | Як іде фреза |
|---|---|
| **заливка** (за замовчуванням) | кільця всередину від краю кожної літери: перше — на радіус фрези від краю (літера не розпливається), далі з кроком карману; між кільцями фреза піднімається на 1 мм |
| по контуру | середньою лінією — центр фрези точно по лінії літер (V-подібна фреза) |
| зовні | фреза зсунута назовні на радіус — обведення навколо літер, самі літери лишаються за розміром |
| всередині | фреза зсунута всередину на радіус — канавка по краю всередині штриха |

> Для дрібного тексту беріть тонку фрезу: якщо штрих літери тонший за фрезу, вона пройде лише по його контуру.

## 9. Імпорт SVG

**`i`** у редакторі — список `.svg` з `~/gcode`, `~/Downloads` і домашньої теки. Фігури лягають **лівим
нижнім кутом у хрестик**, у справжніх міліметрах (з одиниць і viewBox файлу, як їх задав Inkscape).

* Кола, еліпси, прямокутники лишаються собою.
* Криві (`path`: M L H V C S Q T A Z), ламані й повернуті фігури стають **контурами** — ламаними з хордами ~0,3 мм.
* Контур: Enter — середина переносить, правий верхній кут масштабує; пробіл — X / Y, ширина, висота, глибина.
* Замкнені контури мають обробку **зовні / всередині / карман**.

Так можна намалювати складне на комп'ютері в Inkscape, скинути SVG на PicoCalc і тут лише розмістити й
запустити.

## 10. Налаштування $, корекції, входи

**F1 → Налаштування $** — налаштування grblHAL по групах, з назвами, одиницями, межами й описами від самої
прошивки (`$EG` / `$ES` / `$SED`), разом з налаштуваннями плагінів. Бітові поля розкладено по бітах, пошук —
літерами. Enter — змінити (надсилається `$N=…`, потім значення читається назад). «Зберегти всі в файл» —
`~/gcode/settings/<профіль>-дата.txt`; «Відновити з файлу» відкриває такий файл, далі F4 → Запустити весь.
Через telnet grblHAL може не дозволити запис налаштувань.

**Корекції** (F1 → Корекції, у пульті F2–F5): подача ±10 % / ±1 % / 100 %, швидкі 100 / 50 / 25 %, оберти
шпинделя. Рядок «корекції F… R… S…» жовтий, якщо щось не 100 %.

**Входи**: активні сигнали зі звіту (`Pn:`) — червоним: X Y Z — кінцевики, P — щуп, D — двері, H / R / S —
кнопки hold / reset / start, E — E-stop. Натиснули кінцевик рукою — літера з'явилась: зручно перевіряти
проводку.

## 11. Безпека

* Перед запуском файлу перевірте **Межі й перевірка** і, якщо сумніваєтесь, **Обвести межі**.
* «Запустити з рядка» піднімає фрезу на найвищу Z файлу перед переїздом — переконайтесь, що там немає
  затискачів вище.
* Програмна аварійна зупинка (ПРОБІЛ, Ctrl+X) зупиняє рух і шпиндель скиданням grbl, але **не замінює
  апаратний E-stop**.
* Після аварійної зупинки чи кінцевика — `$X` (Backspace) і, бажано, хомінг `$H`.

## 12. Шпаргалка клавіш

**Термінал**

| | |
|---|---|
| F1 | меню (профіль, редактор, файл, порт, grblHAL, налаштування, корекції, довідка, вихід) |
| F2 / Tab | показати / сховати повний вивід |
| F3 / Ctrl+P | порт або мережа |
| F4 / Ctrl+O | файл G-code |
| F5 / Ctrl+G | grblHAL: опитування, скидання, `$X`, `$H`, `$$`… |
| Ctrl+T | пульт |
| Ctrl+E | пояснення помилки |
| Backspace (порожній рядок, Alarm) | `$X` |
| `telnet <IP> [порт]` | профіль через мережу |
| `quit` | вийти |

**Перегляд траєкторії**: стрілки — хрестик / рядки · Tab — вікно G-code · Enter — запуск з рядка · `r` — з
початку · пробіл — пауза · Ctrl+X — стоп · `f` — стежити · `v` — XY / XZ · `+` `-` `0` — масштаб · F1 —
довідка · Esc — закрити.

**Редактор фігур**: `c e r a l t T` — фігури · Enter — точка / редагувати точки · пробіл — числа · Tab —
наступна фігура · Del — видалити · `u` — назад · `p` — параметри · `s` — зберегти як · `o` — відкрити · `i` —
імпорт SVG · `g` — сітка · `+ - 0 h` — вигляд · F1 — довідка · Esc Esc — вийти.
